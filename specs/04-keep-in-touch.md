# Фича «Пора написать» (keep-in-touch)

## Зачем

Цель продукта — «не терять людей». Приложение помнит, **о чём** договорились, но не помнит, **что давно
не общались**. Эта фича говорит: «с Анной ты хотел общаться раз в месяц, а прошло 45 дней — пора написать».

## Решения автора (18.09.2026)

1. **Отсчёт** — и от заметки, и от кнопки «Пообщались». Заметка обнуляет срок; кнопка — для случаев
   «перекинулись парой слов», когда писать нечего.
2. **Ритм свой у каждого, из списка**: не следить (по умолчанию) · раз в 2 недели · раз в месяц ·
   раз в 3 месяца · раз в полгода · раз в год.
3. **Где видно** — переключатель над списком «Все · Пора написать 7» и строка под именем в карточке.

## Решения автора (19.09.2026)

4. **«Пообщались» прямо в списке.** В режиме «Пора написать» у каждой строки справа значок ✓ — отметить,
   не открывая карточку.
5. **Ритм меняется прямо в карточке** — выпадающим списком под именем, без «Изменить» → «Сохранить».

## Как работает

- **Последний раз общались** = самое позднее из: последняя заметка, последнее нажатие «Пообщались».
  Если ни того, ни другого нет — дата, когда контакт добавили.
- **Прошло дней** — календарных, по часам этого компьютера (как «сегодня»/«вчера» в ленте).
- **Пора написать**, когда прошло дней ≥ ритма. Раз в месяц = 30 дней, раз в 2 недели = 14, раз в 3
  месяца = 90, раз в полгода = 180, раз в год = 365.
- Удалили заметку — отсчёт пересчитается по оставшимся.
- Уведомлений нет: только внутри приложения (уведомления сознательно отложены, план, раздел 4).

## Экран

**Над списком** — две ссылки: «Все» и «Пора написать 7». Выбранная помечена `aria-current`; открытая
карточка при переключении остаётся. Адрес: `/?due=1` (с поиском `/?q=анн&due=1`). Обновил страницу — режим на месте.

**Режим «Пора написать»:**

- слева только те, кому пора; сверху — кто дольше всех без общения (порядок совпадает с днями в строках), при равенстве — по алфавиту;
- справа в строке — сколько дней без общения: «45 дней»;
- счётчик: «7 контактов», при поиске — «Найдено 2 из 7»;
- поиск по имени работает внутри режима;
- справа в каждой строке — значок ✓ «Пообщались» (подсказка при наведении; программа экранного доступа
  читает «Пообщались: Анна Петрова»). Нажал — человек уходит из списка, карточка не открывается; если
  фокус был на ✓, он переходит на ✓ следующей строки;
- открыл контакт, записал заметку или нажал «Пообщались» — он уходит из списка, карточка остаётся открытой;
- «Изменить», «Отмена», удаление контакта, «К списку» — возвращают в тот же режим.

**Карточка** — строка под именем, всегда. В начале — выпадающий список «Как часто общаться» («Не
следить», «Раз в 2 недели» … «Раз в год»). Выбрал — сразу сохранилось, без «Изменить» и «Сохранить».
Если ритм задан, дальше:

- «[Раз в месяц ▾] · пора написать: 45 дней без общения»
- «[Раз в месяц ▾] · следующий раз через 18 дней»

и кнопка «Пообщались». Пока сохраняется — «Отмечаю…» и заблокирована. Строка объявляется программам
экранного доступа, когда меняется. «Не следить» — строка и кнопка пропадают, остаётся только список.

**Форма контакта** — поле-список «Как часто общаться» после телефона и почты.

## Плохой день

- «Пообщались» не сохранилось — красная строка «Не удалось отметить» + «Повторить» (в списке — под строкой
  человека, он остаётся в списке).
- Ритм в карточке не сохранился — список возвращается к сохранённому значению, красная строка «Не удалось
  сохранить, как часто общаться» + «Повторить».
- Контакт удалили в другой вкладке — «Такого контакта больше нет».
- Никому не пора — «Сейчас никому не пора писать» и подсказка, где задать ритм.
- В режиме «Пора написать» поиск ничего не нашёл — «Среди тех, кому пора написать, никого не нашлось» +
  ссылка «Искать среди всех».
- Нажал «Пообщались» по ошибке — отменить нельзя; срок просто начнётся заново (см. «Не входит»).

## Данные

Две новые колонки в `contacts`, обе необязательные:

| Колонка              | Тип                         | Правило                                                    |
| -------------------- | --------------------------- | ---------------------------------------------------------- |
| `keep_in_touch_days` | integer, null               | null = не следить; иначе одно из 14, 30, 90, 180, 365      |
| `talked_at`          | integer (unix ms), null     | когда последний раз нажали «Пообщались»                    |

Первичное наполнение: примерно у 4% выдуманных контактов есть ритм, часть из них уже просрочена. У
героев эскизов: Анна Петрова (ProductCamp) — раз в месяц, Дарья Лебедева — раз в 2 недели, Вера
Соколова — раз в 3 месяца. Чтобы увидеть их в своей базе, нужен `npm run db:reset` (удалит всё, что
внесено руками); `npm run db:migrate` только добавит колонки, ритмов не будет.

## Словарь

| В интерфейсе              | В коде                                     |
| ------------------------- | ------------------------------------------ |
| как часто общаться (ритм) | `keepInTouchDays` / `keep_in_touch_days`   |
| пообщались                | `talkedAt` / `talked_at`, действие `markTalked` |
| последний раз общались    | `lastTalkAt` (вычисляется, не хранится)    |
| пора написать (режим списка) | `isDueList`, адрес `?due=1`             |
| этому человеку пора написать | `isDue` в `KeepInTouchState`            |

Правила отсчёта — только `keep-in-touch.ts`; допустимые ритмы — только `validation.ts`; подписи и
склонения — только `format.ts`.

## Не входит

Уведомления (push, почта), «отложить на неделю», отмена «Пообщались», свой ритм в днях, история нажатий
«Пообщались» в ленте.

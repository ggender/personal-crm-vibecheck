# Группы контактов

## Зачем

999 человек одним списком — это много. Группы раскладывают их по полочкам: «Работа», «Соседи», «Друзья».
Открыл группу — видишь только своих из неё; поиск и «Пора написать» работают внутри неё.

## Решения автора (19.09.2026)

1. **У контакта может быть несколько групп.** Анна с ProductCamp — и в «Работе», и в «Конференциях».
2. **Создавать группы можно в двух местах:** в панели «Группы» (там же переименовать и удалить) и прямо
   в форме контакта.
3. **Смотреть группу — рядом над списком:** «Все группы · Работа 114 · … · Без группы».

## Как работает

- Группы у каждого аккаунта свои. Чужие группы не видны, как и чужие контакты.
- Название — от 1 до 50 знаков. Два одинаковых названия у одного аккаунта нельзя; «Работа», «работа» и
  «РАБОТА» — одно и то же название (как в поиске: регистр, «ё»/«е» и лишние пробелы не важны).
- Переименовать группу можно, в том числе поменять только заглавную букву.
- **Удалили группу — контакты остаются**, пропадает только сама группа.
- Удалили контакт — он пропадает из всех своих групп.
- Число рядом с группой — сколько в ней людей всего, без учёта поиска и «Пора написать». Число у «Пора
  написать» по-прежнему считает всех, без учёта группы.
- «Без группы» — те, кто не входит ни в одну группу.

## Экран

**Над списком**, под «Все · Пора написать 7» — ряд групп: «Все группы», группы по алфавиту с числом людей,
«Без группы», и в конце значок «Настроить группы». Выбранная помечена `aria-current`. Адрес: `/?group=3`,
`/?group=none` для «Без группы»; вместе с поиском и «Пора написать» — `/?q=анн&due=1&group=3`. Обновил
страницу — группа на месте. Пока групп нет, вместо ряда — ссылка «Создать группу».
На узком экране ряд групп — одна строка, прокручивается вбок, чтобы списку хватило места.

**Список в группе:**

- счётчик: «114 контактов», при поиске — «Найдено 2 из 114»; в «Пора написать» — только те из группы,
  кому пора;
- открыл контакт, изменил, удалил, «Отмена», «К списку» — группа остаётся выбранной;
- «+» внутри группы открывает форму нового контакта, где эта группа уже отмечена; после «Добавить»
  группа остаётся выбранной, если человек в неё попал.

**Панель «Группы»** (справа, адрес `/?groups=1`): заголовок «Группы», поле «Новая группа» (курсор уже в
нём) и кнопка «Создать группу»; ниже — все группы по алфавиту: название, «114 контактов», «Переименовать»,
«Удалить». «Переименовать» превращает строку в поле с названием + «Сохранить» и «Отмена» (Enter —
сохранить, Esc — отмена). «Удалить» спрашивает: «Удалить группу «Работа»?» — «Контакты останутся —
пропадёт только группа». Внизу — «Готово», обратно к списку.

**Форма контакта** — после «Как часто общаться» блок «Группы»: галочки у всех групп и строка «Новая
группа» + «Создать группу». Новая группа сразу появляется отмеченной; введённое в форме не теряется. Enter
в строке «Новая группа» создаёт группу, а не сохраняет контакт.

**Карточка** — в блоке данных после «Откуда знакомы» строка «Группы»: «Конференции, Работа» или «без
группы».

## Плохой день

- Пустое название — «Напиши название группы»; длиннее 50 — «Название группы длиннее 50 знаков — сократи
  его». Введённое не стирается.
- Такое название уже есть — «Группа «Работа» уже есть».
- Группа не создалась, не переименовалась или не удалилась (приложение не отвечает) — красная строка с
  причиной + «Повторить»; название остаётся в поле.
- Группу удалили в другой вкладке — «Такой группы больше нет». Ссылка на удалённую или чужую группу
  (`/?group=…`) показывает всех, как «Все группы».
- В форме отмечена группа, которую тем временем удалили в другой вкладке, — контакт сохраняется, просто
  без неё.
- В группе никого — «В группе «Работа» пока никого» и подсказка, где отметить группы; в «Без группы»
  никого — «Все контакты разложены по группам».
- Поиск в группе ничего не нашёл — «В группе «Работа» никого не нашлось» + «Искать среди всех».

## Когда… / Тогда…

- Когда человек создаёт группу в панели, тогда она появляется в списке панели и в ряду над списком.
- Когда человек создаёт группу с названием, которое уже есть (в любом регистре), тогда группа не
  создаётся, и он видит «Группа «…» уже есть».
- Когда человек отмечает у контакта две группы, тогда контакт виден в каждой из них, а в карточке —
  обе через запятую.
- Когда человек выбирает группу над списком, тогда в списке только люди из неё, а открытая карточка
  остаётся.
- Когда человек удаляет группу, тогда её люди остаются в списке «Все» и в своих остальных группах.
- Когда человек открывает чужую группу по номеру, тогда видит все свои контакты, как без группы.

## Данные

| Таблица          | Колонка        | Тип                                      | Правило                                          |
| ---------------- | -------------- | ---------------------------------------- | ------------------------------------------------ |
| `groups`         | `id`           | integer, PK                              |                                                  |
|                  | `owner_id`     | integer, not null → `users.id` CASCADE   | чья группа                                       |
|                  | `name`         | text, not null                           | 1–50 знаков после обрезки пробелов               |
|                  | `name_search`  | text, not null                           | всегда `normalizeName(name)`; уникален вместе с `owner_id` |
| `contact_groups` | `contact_id`   | integer → `contacts.id` CASCADE          | PK вместе с `group_id`                            |
|                  | `group_id`     | integer → `groups.id` CASCADE, индекс    |                                                  |

Связь пишет только репозиторий контактов и только с группами того же аккаунта.

Первичное наполнение: у `demo@example.com` шесть групп — Работа, Конференции, Соседи, Учёба, Спорт,
Друзья. Примерно треть контактов разложена по ним по «откуда знакомы» (коллега → «Работа», соседка по даче
→ «Соседи»; конференция — сразу «Работа» и «Конференции»). У героев эскизов: Анна Петрова (ProductCamp) —
Работа и Конференции, Анна Петрова (соседка) — Соседи, Борис Ковалёв — Работа, Вера Соколова — Соседи,
Дарья Лебедева — Друзья. Чтобы увидеть их в своей базе, нужен `npm run db:reset` (удалит всё, что внесено
руками); `npm run db:migrate` только добавит пустые таблицы.

## Словарь

| В интерфейсе                    | В коде                                                   |
| ------------------------------- | -------------------------------------------------------- |
| группа                          | `group` / таблица `groups`, `Group`                      |
| группы контакта (галочки)       | `groupIds`, таблица `contact_groups` (`contactGroups`)   |
| какая группа показана над списком | `groupFilter` (`GroupFilter`: номер, `"none"` или `null`), адрес `?group=` |
| без группы                      | `groupFilter = "none"`, адрес `?group=none`              |
| ряд групп над списком           | `GroupSwitch`                                            |
| панель «Группы»                 | `GroupsPanel`, `isGroupsPanel`, адрес `?groups=1`        |

Правила ввода — только `validation.ts`; запросы — только `data/groups-repo.ts` (группы) и
`data/contacts-repo.ts` (группы контакта и фильтр списка); склонения и вопрос об удалении — только
`format.ts`; адрес — только `screen-url.ts`.

## Не входит

Цвета и значки групп, свой порядок групп (только по алфавиту), вложенные группы, группа у заметки,
массовое добавление в группу из списка, «показать сразу две группы», группы в строке списка.

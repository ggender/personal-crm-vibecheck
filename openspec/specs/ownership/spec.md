# ownership Specification

## Purpose
У каждого пользователя свои контакты, заметки и группы. Чужие данные не просто скрыты: они выглядят как несуществующие, а действие без действующей сессии отвергается, не трогая данных.

## Requirements

### Requirement: Каждому свой блокнот
Система SHALL показывать новому пользователю пустой список без чужих контактов и групп. Все списки, поиск, счётчики и панель групп содержат только данные текущего пользователя.

#### Scenario: Новый адрес
- **WHEN** вошёл пользователь с новым адресом
- **THEN** над списком «0 контактов», групп нет

#### Scenario: Списки только свои
- **WHEN** у другого пользователя есть контакты и группы
- **THEN** их нет в списке, поиске, счётчике, ряду групп и списке группы текущего пользователя

### Requirement: Чужой контакт выглядит как несуществующий
Система SHALL отвечать на любое обращение к чужому контакту так же, как к несуществующему: по адресу — «Такого контакта больше нет»; изменить, отметить «Пообщались», сменить ритм, удалить, добавить в группу или убрать из группы — «Такого контакта больше нет» без повтора.

#### Scenario: Чужой контакт по адресу
- **WHEN** новый пользователь открыл `/?contact=1`, где 1 — контакт другого пользователя
- **THEN** показано «Такого контакта больше нет»

#### Scenario: Чужой контакт нельзя изменить
- **WHEN** действие изменения, отметки, ритма или удаления направлено на чужой контакт
- **THEN** ответ как для несуществующего, данные не изменены

#### Scenario: Группы чужого контакта
- **WHEN** попытка добавить чужой контакт в свою группу или убрать из неё
- **THEN** ответ «Такого контакта больше нет», связи не изменены

### Requirement: Чужие группы и заметки
Система SHALL не показывать чужие группы и не давать их переименовать или удалить («Такой группы больше нет»); чужую группу нельзя привязать к своему контакту, она пропускается. Заметки чужого контакта не видны и не считаются; добавить к нему заметку — «Такого контакта больше нет — заметку некуда сохранить»; удалить чужую заметку — «Этой заметки уже нет». Одинаковые названия групп у разных пользователей допустимы.

#### Scenario: Чужие группы
- **WHEN** у другого пользователя есть группа «Работа»
- **THEN** её нет в ряду и панели, переименовать или удалить её нельзя, а свою «Работа» создать можно

#### Scenario: Чужая группа в форме
- **WHEN** в сохранение контакта передан идентификатор чужой группы
- **THEN** контакт сохранён без неё

#### Scenario: Чужие заметки
- **WHEN** обращение к заметкам чужого контакта
- **THEN** список пуст, счётчик 0, добавить и удалить нельзя

### Requirement: Истёкшая сессия
Система SHALL при любом действии без действующей сессии (истекла или завершена в другой вкладке) отвечать «Вход истёк — войди снова» без повтора и не трогать данные; введённый на экране текст остаётся. Если сессию не удалось проверить из-за сбоя, действие SHALL ответить своим сообщением с возможностью повторить.

#### Scenario: Действие без сессии
- **WHEN** сессии нет, а отправлено любое действие: заметка, контакт, группа, ритм, отметка, удаление
- **THEN** ответ «Вход истёк — войди снова», база не тронута

#### Scenario: Сессию не удалось проверить
- **WHEN** проверка сессии завершилась сбоем
- **THEN** действие отвечает своим сообщением «Не удалось …» с признаком «можно повторить»

#### Scenario: Текст остаётся на экране
- **WHEN** ответ «Вход истёк — войди снова» получен формой
- **THEN** введённое в форме на месте, показано сообщение без «Повторить»

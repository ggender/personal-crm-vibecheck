# Spec Delta

## Purpose

Личные данные людей из блокнота и секреты входа не попадают в логи и тексты ошибок: в логах только идентификаторы, длины и счётчики.

## ADDED Requirements

### Requirement: Логи без личных данных
Система SHALL писать в лог о действиях только идентификаторы, длины и счётчики: никогда имена, телефоны, почту, тексты заметок и названия групп.

#### Scenario: Логи действий с контактами и заметками
- **WHEN** контакт создан, изменён, удалён, заметка добавлена или удалена, отметка или ритм сохранены
- **THEN** строки лога содержат идентификаторы и длины, но не имя, телефон, почту или текст заметки

#### Scenario: Логи действий с группами
- **WHEN** группа создана, переименована, удалена, контакт добавлен или убран
- **THEN** строки лога содержат идентификаторы и длину названия, но не само название

### Requirement: Ошибки без секретов
Система SHALL описывать ошибки по их корневой причине, без параметров запроса, чтобы токен сессии и текст поиска не попали в лог и на экран.

#### Scenario: Сбой проверки сессии
- **WHEN** база не ответила при проверке сессии
- **THEN** выброшенная ошибка не содержит токен сессии

#### Scenario: Корневая причина в логе
- **WHEN** ошибка обёрнута в другую с параметрами запроса
- **THEN** в лог попадает корневая причина без параметров

#### Scenario: Сбой загрузки экрана
- **WHEN** экран не удалось построить из-за базы
- **THEN** ошибка на экране и в логе не содержит текст поиска

### Requirement: Вход без следов в логе
Система SHALL при отправке письма для входа логировать только факт отправки, при сбое — только код почтового сервера, без адреса и ссылки; при выходе — идентификатор пользователя, не адрес. Токен ссылки для входа SHALL храниться в базе только хешем.

#### Scenario: Письмо не отправилось
- **WHEN** почтовый сервер отказал
- **THEN** в лог записан код ошибки, адреса и ссылки в логе нет

#### Scenario: Выход
- **WHEN** пользователь вышел
- **THEN** в логе идентификатор пользователя, адреса нет

#### Scenario: Токен ссылки
- **WHEN** ссылка для входа создана
- **THEN** в базе хранится только хеш её токена

#### Scenario: Сообщения библиотеки входа
- **WHEN** библиотека входа пишет в лог
- **THEN** записывается только уровень и событие, без её текста

# Tasks

Каждая задача называет сценарий спеки, который доказывает тест. Проверка задачи — тест проходит в `npm run test:e2e` или `npm test`, а его шаги совпадают со сценарием.

## 1. e2e/scenarios.spec.ts — демо-аккаунт

- [x] 1.1 contacts «Курсор в поле имени» и «Enter в текстовом поле сохраняет»: форма открылась с фокусом в имени; Enter в имени сохраняет; Enter в «О чём договорились» переносит строку
- [x] 1.2 contacts «Отмена без изменений»: изменил имя в форме, «Отмена» — карточка с прежним именем
- [x] 1.3 contacts «Приложение не отвечает»: обрыв запросов при сохранении формы — сообщение с «Повторить», поля целы; после повтора карточка открыта
- [x] 1.4 contacts «Пустые поля и ссылки»: «не указано» трижды у пустого контакта; телефон и почта — ссылки `tel:` и `mailto:`
- [x] 1.5 contacts «Выбранный контакт отмечен в списке»: у открытой строки `aria-current="page"`; контакт из конца списка после перехода по адресу в зоне видимости
- [x] 1.6 contacts «Переход к карточке с клавиатуры»: Shift+Tab из поиска — ссылка «Перейти к карточке», Enter — фокус на панели карточки
- [x] 1.7 contacts «Подсказка на старте»: на `/` заголовок «С кем ты только что говорил?» и фокус в поиске
- [x] 1.8 search «Пауза после ввода»: три буквы с паузами меньше 250 мс — запроса нет, после 250 мс — один
- [x] 1.9 search «Enter отправляет сразу»: Enter при замороженных часах даёт запрос без паузы
- [x] 1.10 notes «Счётчик знаков»: 4500 знаков — «4500 из 5000 знаков»; 5001 — поле помечено ошибкой
- [x] 1.11 notes «Лента пуста»: у нового контакта без заметки — «Заметок пока нет. Запиши, о чём договорились.»
- [x] 1.12 notes «Окно подтверждения»: «Удалить заметку» — окно с вопросом и фокусом на «Отмена»; после «Удалить» окно закрыто, фокус в поле заметки

- [x] 1.15 ownership «Текст остаётся на экране»: без cookie сессии сохранение заметки отвечает «Вход истёк — войди снова» без «Повторить», текст в поле
- [x] 1.16 database-status «Экран ошибки» и privacy «Сбой загрузки экрана»: таблица `contacts` переименована — «Что-то сломалось», «Попробовать снова», «Код ошибки», слова из `q` нет в тексте; после восстановления «Попробовать снова» показывает список
